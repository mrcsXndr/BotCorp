# TDL — To-Do List (the always-in-memory backlog)

The single durable, hand-maintained record of everything undone, blocked, or
deferred. Session start injects the `## Open` section. Edit this file directly
with Edit/Write — no CLI, no schema. Each `###` item can carry as much detail
as it needs: status tag, exact next step, blocker, links.
