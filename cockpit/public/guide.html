How the cockpit works

One page for every bot on this machine: its live terminal, a chat view of the same session, and the operator actions the daemon exposes.

What you see

The left column lists every bot (every bots/<name>/bot.yaml). A green stub means its session is up. Pick one to attach: Chat shows the conversation as bubbles, Terminal shows the raw Claude Code screen.

Start, stop, restart

These ask the daemon (through botcorp start|stop|restart). The cockpit never starts a session itself, so closing this page or updating the cockpit never kills a bot. Restart fresh (under more) starts a new session instead of continuing the last one.

From a phone

  1. Chat view is the default on narrow screens: type, press Enter.
  2. In Terminal view the key row gives you Esc, Ctrl+C, Ctrl+L (redraw), Mode, Tab, Enter and arrows.
  3. +file (or drop, or paste) uploads an image or a file and types its path into the prompt. Add your question and press Enter.

Telegram

Whoever messages the bot first gets a pairing code and appears under pairing. Approve them there (or type a numeric Telegram id). Nothing a stranger writes reaches the bot before that.

Vault

Secrets (the Claude OAuth token, a Telegram bot token) are stored encrypted on this machine and never shown again. Set a key to replace its value.

Remote Control

Optional. Enable Remote Control runs /login in the terminal and surfaces the link; Start Remote Control runs /remote-control and surfaces the claude.ai link for your phone. Those sessions are stored by Anthropic.

Something looks stuck

Press Restart. The session continues where it was. If the session exited, the red bar says so and offers a restart.
